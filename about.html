ABOUT US

让图片处理变得简单、安心。

图工具箱是一套轻量、免费、无需登录的在线图片工具，帮助你快速完成图片压缩、格式转换、尺寸调整和批量打包。所有操作都在你的浏览器中完成，图片始终留在你的设备上。

我们是谁

我们是一群喜欢把复杂事情做简单的人。图工具箱诞生于一个朴素的想法：处理一张图片不应该要求安装大型软件、创建账号，或把私人文件上传到陌生服务器。我们专注于做好日常图片处理所需要的功能，让每个人都能随时打开浏览器完成任务。

为什么做这个站

很多图片工具功能繁杂、广告干扰明显，还要求用户上传文件。我们希望提供一个更直接的选择：打开即用，操作清晰，处理速度快，并且从设计上优先保护图片隐私。无论是整理相册、准备网页素材，还是压缩附件，图工具箱都可以帮你节省时间。

技术说明

图工具箱基于现代浏览器能力构建，尽量把处理过程放在用户设备上完成。

  • 使用 HTML5 Canvas 读取、绘制和导出图片
  • 使用 File API 访问用户主动选择的本地文件
  • 支持 JPG、PNG、WebP 格式转换与尺寸调整
  • 浏览器本地生成结果，处理完成后即可下载
